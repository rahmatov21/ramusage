⚡ What Happens Automatically on the Worker PC

🛡️ Zero Admin Privileges

Runs entirely inside your Windows user profile (`%USERPROFILE%\DistributedMeshWorker`). Never asks for administrator elevation or UAC.

👻 100% Invisible Background

Runs silently using `pythonw.exe` and a headless VBScript runner. No taskbar icon, console window, or popups appear.

🔄 Power Outage Auto-Start

Configured in Windows startup (`HKCU\Run`). Whenever electricity turns back on, the node automatically launches and connects.

🧠 Zero Model Upload

Scans existing models in LM Studio and Ollama directly from the local hard drive. No multi-gigabyte uploads needed.

💻 PowerShell Laptop Control Commands

From your laptop, open PowerShell in the project folder and use `.\mesh.ps1` to control everything:

.\mesh.ps1 pcs

Shows total connected PCs (online vs offline), IP addresses, and free RAM per machine.

.\mesh.ps1 models

Lists all downloaded models found across all PCs (LM Studio, Ollama, GGUF) with parameters and layer counts.

.\mesh.ps1 load 1

Loads model #1. The cluster calculates each PC's free RAM, splits the layers, and activates distributed inference.

.\mesh.ps1 ask "Hello! What can you help me with?"

Sends an inference prompt directly to the distributed AI cluster.

.\mesh.ps1 clean

Flushes process working sets and reclaims unused RAM across all connected computers.

.\mesh.ps1 unload

Unloads active model and releases all memory allocations.

🚨 CODE RED: Remote Wipe & Clean Uninstall

Sends a self-destruct wipe signal to all worker PCs. Kills all running worker processes, removes Windows startup registry keys, and deletes the entire application folder and logs as if the software never existed.

.\mesh.ps1 codered

🧠 Architecture & Frequently Asked Questions

Q: Do I need to download the model on every computer?

NO. You only download the model file on one computer (e.g. in LM Studio). When you choose that model, the system reads the model weights from that disk and streams the assigned layers directly into the other computers' RAM over LAN. The other computers use zero hard drive space!

Q: What happens if electricity goes off and comes back on?

As long as your PC BIOS is set to "Restore on AC Power Loss: Power On", Windows turns on automatically. The worker node is registered in your Windows startup folder and silently reconnects to the Master PC as soon as the network comes online.

Q: Do I need a Telegram bot token right now?

NO. You have full control from your laptop using PowerShell (`.\mesh.ps1`). Telegram is 100% optional and disabled by default.

Q: Does any script require Administrator rights?

None. Everything installs and runs in user-space permissions (`pip install --user`, HKCU registry keys, Win32 memory APIs).
